Configuración del foro

Sólo para quien administra el repositorio. Se hace una vez (y otra cuando caduque el token).

  1. Entra en GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: «Only select repositories» → elige sólo este repositorio.
  3. Permissions → Repository permissions → Contents: «Read and write». Nada más.
  4. Copia el token y pégalo aquí junto con la frase de acceso que daréis a los miembros.

La frase cifra todo el contenido del foro y el token. Usa al menos 5 palabras al azar y compártela sólo en persona o por un canal seguro. Si renuevas el token, escribe la misma frase de siempre.
